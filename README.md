## 🚀 Overview

Charlie is a modular AI desktop assistant designed to provide a natural and intelligent user experience through voice interaction, automation, and an interactive 3D avatar.

The project focuses on privacy and modularity by supporting offline speech synthesis, local AI integrations, and an extensible architecture that allows new capabilities to be added easily.
## ✨ Features

- 🎤 Wake word detection
- 🗣️ Speech-to-text interaction
- 🔊 Offline text-to-speech (Piper)
- 👩 Real-time 3D VRM avatar
- 👄 Lip-sync and facial expressions
- 🧠 Long-term memory
- 📅 Calendar support
- 📋 Task management
- 📇 Contact management
- 📸 Screenshot capture
- 🎥 Camera integration
- 💻 Desktop automation
- ⚙️ Modular architecture

```bash

cd charlie-ai-assistant

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python main.py
```
