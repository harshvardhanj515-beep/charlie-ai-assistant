# Security Policy

## Supported Versions

Currently, only the latest version of Charlie on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please **do not** create a public GitHub issue.

Instead, please send an email directly to the maintainer. We take all security vulnerabilities seriously and will work to resolve the issue promptly.

When reporting an issue, please provide:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Any possible solutions you have in mind.

You should receive a response within 48 hours. If the vulnerability is accepted, we will coordinate a fix and an announcement.
